# 법인과 회사 구조 이해하기 3: 세무·회계의 기초 (퀀트 실무자 관점)

## 영업이익 vs 당기순이익 괴리 → 퀄리티 시그널

본문이 강조하는 "영업이익은 플러스인데 당기순이익이 크게 다른 이유"는 퀀트 실무에서 **Accrual(발생액) 분석**과 직결된다. Sloan(1996)의 고전적 발견은 발생액 비중이 높은 이익(현금흐름과 괴리가 큰 이익)일수록 향후 수익률이 낮다는 것이다.

```
Accrual Ratio = (당기순이익 - 영업현금흐름) / 총자산
```

이 비율이 높은(이익의 질이 낮은) 종목을 롱-숏 팩터의 숏 후보로 사용하는 것은 학계에서 반복 검증된 이례현상(anomaly)이다.

## 세무조정·감사의견 → 데이터 신뢰도 리스크

감사의견(적정/한정/부적정/의견거절)은 퀀트 파이프라인에서 **필수 사전 필터**다. 적정의견이 아닌 종목을 유니버스에서 자동 제외하는 규칙은 실무 표준이며, 한정의견이라도 사유(재고 실사 불가, 계속기업 불확실성 등)를 텍스트 마이닝해 리스크 등급을 세분화하는 것이 고도화된 접근이다.

## 기장·증빙 프로세스 → 재무데이터의 원천 이해

이 절 자체는 시그널이 아니지만, 퀀트 실무자가 DART 공시 데이터를 다룰 때 "이 숫자가 왜 이렇게 계산됐는가"를 이해하는 배경지식으로 유용하다. 특히 세무조정으로 인한 회계상 이익과 과세소득의 괴리는, **실효세율(effective tax rate)의 이상치**가 일회성 이벤트(세무조사, 이월결손금 소진 등)의 신호일 수 있음을 시사한다. 실효세율 급변 종목을 이익의 질 필터에 추가하는 것도 실무에서 쓰이는 방법이다.

## 외부감사 대상 여부 → 유니버스 필터 기준

외부감사법 대상 기준(자산·매출·부채 등)은 퀀트 유니버스를 스몰캡까지 확장할 때, 재무 데이터 신뢰도의 최소 기준선으로 활용된다. 비외부감사 대상 소형주는 재무제표 오류/조작 리스크가 상대적으로 높아, 팩터 백테스트에 포함할 경우 별도의 데이터 클리닝이 필요하다.

## 실무 체크리스트

1. Accrual Ratio를 이익 퀄리티 필터로 팩터 모델에 포함했는가
2. 감사의견 비적정 종목을 유니버스에서 사전 제외했는가
3. 실효세율 급변 등 회계 이상 신호를 리스크 플래그로 모니터링하는가
