# 거시경제와 주식시장 읽기 (퀀트 실무자 관점)

## 거시지표 → 매크로 팩터 모델의 입력변수

본문의 "지표→금리·환율→기업이익→주가" 4단계 프레임은 정성적으로 옳지만, 퀀트 실무에서는 이를 **팩터 익스포저 추정**으로 구체화한다.

```
R_sector = α + β_rate·ΔRate + β_fx·ΔFX + β_oil·ΔOil + ε
```

롤링 회귀로 업종별 매크로 베타를 추정하면, "금리 상승기에 어떤 업종이 취약한가"를 사후 서술이 아니라 사전 정량 지표로 답할 수 있다. 이는 매크로 헤지 오버레이 설계(예: 금리 베타가 높은 포트폴리오에 국채선물 숏을 결합)의 기초가 된다.

## 중앙은행의 역할 → 매크로 팩터 모델의 상위 구조

중앙은행이 통화·금융시스템의 기반이라는 서술은, 퀀트 실무에서는 **기준금리 결정 자체를 예측 대상이 아니라 조건부 변수(conditioning variable)**로 다루는 것으로 구체화된다.

- 기준금리 자체의 방향을 맞추려는 시도(재량적 매크로 예측)는 퀀트 파이프라인의 핵심이 아니다 — 대신 "기준금리가 오를 때/내릴 때 각 팩터·업종의 조건부 수익률 분포가 어떻게 달라지는가"를 과거 데이터로 정량화하는 것이 실무적 접근이다
- 통화정책 이벤트(금통위, FOMC)는 위 09번 문서의 이벤트 태깅 데이터베이스에 사전 정의된 카테고리로 포함해, 발표 전후 변동성 확대 폭을 GARCH 계열 모델의 외생 변수로 투입한다
- 중앙은행의 정책 커뮤니케이션(포워드 가이던스) 톤 변화는 10번 문서에서 다루는 RAG 기반 텍스트 팩터(관리자 톤 팩터와 동일한 방법론)로 정량화할 수 있다 — 회의록·성명서의 매파적/비둘기파적 어조 변화를 시계열로 추적하는 접근이 실무에서 쓰인다

## 기준금리 흐름과 자산별 금리 민감도 — 팩터 로테이션의 실행 단계

기준금리 변화가 자산군마다 다르게 반응한다는 서술을, 실무에서는 자산군별 **금리 베타**로 정량화해 로테이션 실행에 직접 연결한다.

| 자산군 | 금리 민감도 특성 | 실무 반영 |
|---|---|---|
| 장기 성장주 | 금리 민감도(밸류에이션 듀레이션) 큼 | 03번 문서의 현금흐름 듀레이션 팩터로 정량화 |
| 장기채 | 듀레이션에 정비례해 금리 민감 | 채권 듀레이션 팩터로 직접 측정 가능 |
| 배당주·가치주 | 상대적으로 금리 민감도 낮음 | 금리 상승기 팩터 로테이션의 대안 익스포저 |
| 은행·금융주 | 순이자마진 확대로 금리 상승 시 유리한 경우多 | 업종 고유 요인이므로 별도 팩터로 분리 |

이 표를 "수출주는 유리, 성장주는 불리" 식의 정성 서술로 남겨두지 않고, 각 자산군의 과거 금리 변화 구간별 조건부 수익률을 실제로 집계해 로테이션 전략의 룰(rule)로 코딩하는 것이 다음 단계다.

## 월별 시장 변동 복기표 → 이벤트 태깅의 방법론적 함정

본문 자체가 "키워드로 다음 달을 예측하지 말라"고 경고하듯, 이런 사후 내러티브(narrative fitting)는 퀀트 리서치에서 가장 흔한 오류 중 하나다. 사후적으로 그럴듯한 설명을 찾는 것(hindsight bias)과 사전에 검증 가능한 시그널을 만드는 것은 다르다. 실무적으로 유의미하게 쓰려면:

- 이벤트를 사전 정의된 카테고리(통화정책, 지정학, 실적시즌 등)로 태깅한 **이벤트 데이터베이스**를 구축
- 각 카테고리별 과거 발생 시 평균 변동성 확대 폭을 정량화(예: 지정학 리스크 이벤트 발생 시 VIX 평균 상승폭)
- 이를 조건부 변동성 예측 모델(GARCH 계열)의 외생 변수로 투입

## 8월 계절성(코스피) → 계절성 팩터 검증의 표준 절차

본문이 스스로 "10개 표본으로 매매 규칙을 만들기엔 근거가 약하다"고 지적한 것은 정확하다. 계절성 효과(월별 효과, 산타랠리 등)를 실무에서 검증하는 절차는:

1. **표본 확대**: 가능한 한 긴 기간(수십 년)과 다수 시장으로 검증
2. **통계적 유의성**: t-검정으로 해당 월 수익률이 다른 월과 유의하게 다른지 확인 (10개 표본으로는 통상 유의성 확보 불가)
3. **경제적 정합성**: 계절성이 설명 가능한 메커니즘(펀드 리밸런싱, 세금 손실 매도 등)과 연결되는지
4. **표본외 검증**: 발견 이후 기간에도 효과가 지속되는지(많은 계절성 효과는 발견 후 사라짐 — publication bias)

산타랠리도 마찬가지로, 미국 시장 다수 연구에서는 약하지만 유의한 효과가 보고되나, 한국 시장에 그대로 적용 가능한지는 별도 검증이 필요하다.

## 수익률곡선·할인율 → 팩터 로테이션의 매크로 트리거

수익률곡선 스티프닝/플래트닝은 밸류-그로스 팩터 로테이션의 전형적 트리거로 쓰인다. 장기금리 급등 국면에서는 듀레이션이 긴(장기 현금흐름 비중이 큰) 성장주가 할인율 상승에 더 민감하다는 것을 앞서 03번 문서에서 다룬 "밸류에이션 듀레이션" 개념으로 정량화할 수 있다. 이를 매크로 팩터 타이밍 모델에 결합하는 것이 실무의 다음 단계다.

## 글로벌 자산·채권시장 규모 비교 → 매크로 익스포저의 상대적 크기 감각

한·중·일·미 자산 규모나 주요국 채권시장 규모 비교 같은 구조적 통계는, 개별 팩터가 아니라 **포트폴리오의 글로벌 매크로 익스포저를 설계할 때의 배경 지도**로 쓰인다.

- 특정 국가·자산군의 시장 규모가 작을수록 외국인 자금 유출입에 따른 가격 충격이 커지는 경향이 있다 — 국내 팩터 전략의 유동성 리스크를 평가할 때, 코스피의 글로벌 시장 대비 상대적 크기를 감안해 외국인 수급 팩터(02번 문서)의 민감도를 조정해야 한다
- 채권시장 규모가 작은 국가는 국채선물·금리스왑(IRS) 시장의 유동성도 제한적인 경우가 많아, 05번 문서에서 다룬 금리 헤지 오버레이의 실행 가능성(체결 가능한 계약 규모)을 사전에 점검해야 한다

## 환율 민감도 → FX 베타의 기업별 추정

"원화 약세=수출주 유리"라는 단순 공식을 본문도 경계하듯, 실무에서는 기업별 **FX 베타를 개별 추정**해야 한다.

```
R_i = α + β_FX·ΔUSDKRW + ε (롤링 60~120일)
```

환헤지 여부·달러 매출 비중·달러 비용 비중이 기업마다 달라 동일 업종 내에서도 베타 부호가 다를 수 있다. 이 베타를 팩터로 사용해 환율 시나리오별 포트폴리오 민감도를 사전에 계산하는 것이 실무 표준이다.

## 실무 체크리스트

1. 매크로-업종 관계를 사후 서술이 아니라 롤링 회귀 베타로 정량화했는가
2. 계절성 효과 검증 시 표본 크기와 통계적 유의성을 확인했는가
3. 이벤트 태깅 데이터베이스를 구축해 조건부 변동성 모델에 활용하는가
4. 기업별 FX 베타를 개별 추정해 업종 단위 일반화를 피했는가
5. 기준금리 변화에 대한 자산군별 조건부 수익률을 실제로 집계해 로테이션 룰로 코딩했는가
6. 글로벌 시장·채권시장 규모 대비 국내 유니버스의 유동성·헤지 실행가능성을 점검했는가
