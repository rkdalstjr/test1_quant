# 법인과 회사 구조 이해하기 2: 운영·자금·신용보증 (퀀트 실무자 관점)

## 현금흐름 개념 → 퀄리티/디스트레스 팩터의 원재료

본문의 현금 소진(cash burn), 런웨이(runway), 캐시카우 개념은 그대로 **상장기업 스크리닝 팩터**로 전환된다.

| 개념 | 팩터화 |
|---|---|
| 현금 소진 | 영업현금흐름 - 필수 자본지출 (음수면 소진 상태) |
| 런웨이 | 현금성자산 / 월평균 소진액 → 낮을수록 유동성 리스크 |
| 캐시카우 여부 | 영업현금흐름의 변동계수(CV)가 낮고 꾸준히 양수 |

이는 Altman Z-Score, Piotroski F-Score 같은 부실 예측/퀄리티 팩터의 구성 요소와 본질적으로 동일하다. 비상장 소기업 운영 원리를 상장기업 유니버스 전체에 표준화해 적용하면 디스트레스 리스크 팩터가 된다.

## 신용보증기금 구조 → 신용 스프레드 이해의 기초

보증부 대출 구조는 회사채 신용 스프레드를 이해하는 기초 모델과 유사하다. 신보의 보증은 "정부가 신용리스크의 일부를 흡수"하는 구조이며, 이는 채권시장에서 보증채·특수채가 무보증 회사채보다 낮은 스프레드로 거래되는 이유와 같은 원리다. 퀀트 채권 전략(크레딧 팩터 투자)을 다룰 때 이 개념이 그대로 확장된다.

## 보증금·증거금 개념의 공통 구조 — 신용보증기금 vs 파생상품 증거금

이 문서의 신용보증(제3자가 채무불이행 리스크 일부를 흡수)과, 선물·옵션 거래의 증거금(계약 당사자가 스스로 손실 담보를 예치)은 표면적으로 다른 제도지만, **"누가 신용리스크를 흡수하는가"를 명시적으로 설계한 장치**라는 점에서 구조가 같다.

- 신용보증기금형 구조: 제3의 보증기관이 리스크를 흡수 → 차주의 신용 스프레드가 낮아짐(보증료가 그 대가)
- 증거금형 구조: 거래 당사자가 자기 손실을 선(先) 담보 → 거래소·청산소가 카운터파티 리스크를 담보 자산으로 상쇄
- 두 구조 모두 "담보/보증이 부족해지는 시점에 강제 조치(마진콜·반대매매, 보증 회수·기한이익 상실)가 발동된다"는 동일한 논리를 따른다 — 상장기업 신용 분석에서 이 유비는, 보증부 채무 비중이 높은 기업일수록 보증기관의 신용도·보증 한도 변화가 해당 기업의 실질 신용 스프레드에 미치는 영향을 별도로 추적해야 한다는 실무 시사점으로 이어진다

## 상환 여력 계산 → 이자보상배율의 미시적 버전

본문의 "월 상환 여력 = 현금유입 - 운영비 - 예비자금" 공식은 상장기업 재무팩터의 **이자보상배율(Interest Coverage Ratio = EBIT/이자비용)**과 개념적으로 동일하다. 퀀트 스크리닝에서는:

```
이자보상배율 < 1.5x → 재무 리스크 플래그
```

같은 임계값 규칙을 팩터 필터로 사용해 부실 위험이 큰 종목을 유니버스에서 제외하거나, 반대로 이 리스크를 공매도/숏 팩터의 후보군으로 활용한다.

## 지분율·연결/별도재무제표 → 팩터 정규화의 실무 이슈

본문 6절의 지분 구조·모자회사 설명은 팩터 데이터 정규화에서 실제로 자주 부딪히는 문제다. 지주회사 구조(예: 삼성물산, LG 등)에서 개별 상장 자회사와 지주사를 동시에 유니버스에 포함하면, 같은 사업 익스포저가 중복 계산되는 **더블 카운팅 리스크**가 생긴다. 팩터 포트폴리오 구성 시 지분 관계도를 기반으로 실질 익스포저를 조정(look-through)하는 절차가 필요하다.

## 실무 체크리스트

1. 현금흐름 기반 디스트레스 팩터를 스크리닝에 반영했는가
2. 이자보상배율 등 재무 건전성 지표를 리스크 필터로 사용하는가
3. 지주사-자회사 중복 익스포저를 look-through 방식으로 조정했는가
4. 보증부 채무 비중이 높은 기업은 보증기관 신용도 변화를 별도 리스크 요인으로 추적하는가
