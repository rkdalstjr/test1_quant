# 주식 3 (퀀트 실무자 관점)

## PER·PBR → 밸류에이션 팩터의 표준화

PER·PBR을 "가격표 비교 도구"로 설명하는 것은 정성적으로는 맞지만, 퀀트 실무에서는 이를 **크로스섹션에서 표준화(z-score, 업종 중립화)**해야 팩터로서 의미가 생긴다.

```
Value_score = (PER_i - mean(PER_sector)) / std(PER_sector)
```

적자 기업은 PER 계산이 불가하므로(본문 지적대로) 퀀트 파이프라인에서는 다음 중 하나를 택한다.

- 결측치로 처리하고 팩터 랭킹에서 제외
- EV/Sales, EV/EBITDA 같은 대체 팩터로 백필(backfill)
- Earnings yield(1/PER)를 사용해 음수 이익을 그대로 반영(적자기업이 자연스럽게 최저 랭크가 됨)

PBR 역시 業種 중립화가 필수다. 금융업과 플랫폼 기업을 같은 PBR 절대값으로 비교하는 것은 팩터 설계 오류다.

## ROE·EPS → 듀폰 분해와 퀄리티 팩터

ROE를 단일 숫자로 쓰지 않고 **듀폰 분해(DuPont decomposition)**로 나눠야 퀄리티 신호와 레버리지 신호를 구분할 수 있다.

```
ROE = 순이익률 × 자산회전율 × 재무레버리지
```

부채 확대로 ROE가 높아진 케이스를 걸러내려면 레버리지 요소를 분리해 별도 팩터(부채비율, 이자보상배율)로 통제해야 한다. 이는 Piotroski F-Score, Sloan Accrual 등 학술적으로 검증된 퀄리티 팩터 설계의 기본 원리와 동일하다.

## 실적 서프라이즈(어닝 서프라이즈) → SUE 팩터

컨센서스 대비 서프라이즈는 **PEAD(Post-Earnings Announcement Drift)** 문헌의 핵심 변수인 SUE(Standardized Unexpected Earnings)로 표준화한다.

```
SUE = (실제 EPS - 컨센서스 EPS) / std(과거 서프라이즈)
```

SUE 상위 종목이 실적 발표 후 수주~수개월에 걸쳐 초과수익을 내는 현상(PEAD)은 여러 시장에서 반복 검증된 이례현상이다. 실무에서는 이를 이벤트 드리븐 팩터로 편입하되, 발표일 이후 체결 가능 시점(T+1 시가 등)을 명확히 정의해 룩어헤드 바이어스를 제거해야 한다.

## 자사주 매입·소각 → EPS 기계적 효과 분리

자사주 소각으로 인한 EPS 개선은 **분모 효과**이며 펀더멘털 개선이 아니다. 퀀트 팩터 설계 시 EPS 성장률을 발행주식수 변화로 분해하여, "진짜 이익 성장"과 "주식수 감소 효과"를 분리한 조정 EPS 성장률을 쓰는 것이 표준이다.

## DCF·WACC·CAPM → 파라미터 민감도 분석이 핵심

DCF는 백테스트 가능한 시그널이라기보다 밸류에이션 프레임이지만, 퀀트 관점에서 중요한 것은 **할인율(WACC) 변화에 대한 가치추정치의 민감도(듀레이션 유사 개념)**다. 장기 성장주는 금리 변화에 대한 밸류에이션 듀레이션이 길다 — 이를 "금리 민감도 팩터"로 정량화하면(예: 종목별 예상 현금흐름의 가중평균 도래기간), 금리 상승기 팩터 로테이션 전략의 입력값이 된다.

베타(β)는 CAPM에서 쓰이지만, 실무에서는 단일 요인 베타보다 Fama-French식 다요인 모델(시장·사이즈·밸류·모멘텀)로 리스크를 분해하는 것이 표준이다.

## 채권 가격-금리 역관계 → 밸류에이션 듀레이션 개념의 원형

"금리가 오르면 채권 가격은 내려간다"는 채권시장의 기초 명제는, 위 DCF 절의 "밸류에이션 듀레이션" 개념과 수학적으로 동일한 구조다.

```
채권가격 변화율 ≈ -Duration × Δ금리
```

이 관계를 주식 밸류에이션에 그대로 대응시키면, 장기 성장주는 사실상 **듀레이션이 긴 채권과 유사한 금리 민감도**를 갖는다는 것이 실무적으로 유용한 유비(analogy)다.

- 종목별 잉여현금흐름의 가중평균 도래기간(cash-flow duration)을 추정하면, 채권 듀레이션과 동일한 방식으로 "금리 1bp 변화당 이론가 변화율"을 계산할 수 있다
- 이를 팩터로 만들면(예: 상위 20% 듀레이션 종목 롱, 하위 20% 숏), 금리 국면별 팩터 로테이션 전략의 입력 변수가 된다
- 채권-주식 간 상관관계는 국면에 따라 부호가 바뀌므로(저금리기 음의 상관 → 고금리·고인플레기 양의 상관으로 전환된 사례가 다수 보고됨), 이 관계를 고정 가정으로 두지 않고 롤링 윈도우로 재추정해야 한다 — 전통적인 60/40 자산배분의 분산 효과가 국면에 따라 약화될 수 있다는 뜻이다

## 랜덤워크·효율적 시장 가설(EMH) → 팩터 투자의 이론적 배경과 반증

"가격에는 이미 알려진 정보가 반영되어 있다"는 EMH는, 액티브 팩터 투자 자체의 존재 근거를 질문하게 만드는 이론이다. 퀀트 실무에서는 이를 다음과 같이 다룬다.

- 강형(strong-form) EMH는 내부정보로도 초과수익이 불가능하다는 주장이며, 대부분의 실증 연구가 이를 기각한다(내부자 거래의 초과수익 보고 사례)
- 준강형(semi-strong-form) EMH는 공개 정보로는 초과수익이 불가능하다는 주장이지만, 모멘텀·밸류·퀄리티 팩터의 반복적 초과수익은 이에 대한 **이례현상(anomaly)**으로 문헌에 축적되어 있다
- 실무적 태도는 "시장이 대체로 효율적이되, 특정 팩터·이벤트 구간에서 체계적 비효율이 남아있고, 그 비효율은 거래비용·리스크 프리미엄·행동편향 중 하나로 설명 가능해야 한다"는 것이다. 설명 불가능한 초과수익은 데이터 마이닝(과최적화)일 가능성을 먼저 의심해야 한다
- 랜덤워크 가설은 가격의 단기 예측 불가능성을 뜻하지만, 이는 "모든 시계열 구조가 없다"는 뜻이 아니다 — 변동성 군집(volatility clustering)처럼 수익률의 2차 모멘트는 예측 가능한 경우가 많으며, 이는 GARCH류 모델의 존재 근거다

## 컨센서스·가이던스 → 애널리스트 예측 데이터의 신뢰도 검증

컨센서스는 참고값이라는 서술은 맞지만, 퀀트에서는 이를 다음과 같이 다룬다.

- 컨센서스 추정치 수(number of estimates)가 적으면 노이즈가 큼 — 최소 N명 이상 필터
- 컨센서스 수정 모멘텀(estimate revision momentum)은 그 자체로 검증된 팩터
- 가이던스 상향/하향을 이진 변수화해 이벤트 스터디에 활용

## 실무 체크리스트

1. 모든 밸류에이션 배수를 업종 중립화·크로스섹션 표준화했는가
2. ROE/EPS 성장을 레버리지·주식수 변화 효과와 분리했는가
3. 어닝 서프라이즈 시그널을 SUE로 표준화하고 PEAD 문헌 기준과 대조했는가
4. DCF 결과의 할인율 민감도를 팩터화해 금리 리스크 관리에 활용하는가
5. 종목별 현금흐름 듀레이션을 추정해 채권 듀레이션과 동일한 방식으로 금리 민감도를 정량화했는가
6. 발견한 초과수익 팩터가 데이터 마이닝이 아니라 거래비용·리스크 프리미엄·행동편향 중 하나로 설명 가능한지 점검했는가
